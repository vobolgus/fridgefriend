Технологии

Надёжный стек для масштабирования до миллионов

📱 Мобильное приложение

  • Flutter 3.24 — iOS + Android из одной базы
  • Riverpod — state management
  • Drift / SQLite — офлайн-кэш
  • SSE — real-time синхронизация
  • Apple Vision / ML Kit — OCR на устройстве

⚙️ Backend

  • FastAPI (Python 3.12) — async API
  • PostgreSQL + SQLAlchemy ORM
  • Redis — кэш и очереди
  • OpenSearch — индекс рецептов
  • LiteLLM gateway — гибкая смена LLM

☁️ Инфраструктура

  • AWS ECS Fargate — авто-масштабирование
  • RDS PostgreSQL + ElastiCache
  • S3 + CloudFront — медиа CDN
  • Terraform IaC — infrastructure as code
  • Firebase FCM · Amplitude · Sentry
